## 📖 Overview

**ak_core** is a full-featured backend framework built for FiveM servers using **TypeScript**.

The goal of this project was not simply to create a FiveM server, but to design a **clean, scalable and maintainable architecture** inspired by modern backend development practices.

The framework focuses on:

* Clean Architecture
* Modular design
* Dependency Injection
* Strict TypeScript
* High maintainability
* Code reusability

---

A centralized player management system.

* Player lifecycle
* Session management
* Jobs
* Inventory

---

## ⚡ Event System

Fully typed event architecture.

* Client Events
* Server Events
* Shared Events
* Event registration
* Event dispatching

---

## 🏗 Modular Architecture

The framework is separated into independent modules.

Example:

```text
src/
├── client/
├── server/
├── shared/
├── managers/
├── services/
├── events/
├── database/
├── interfaces/
├── types/
└── utils/
```

Each module has a single responsibility, making the project easy to extend and maintain.

---

## 💉 Dependency Injection

Services are automatically injected into the components that need them.

Advantages:

* Loose coupling
* Easier testing
* Better maintainability
* Better scalability

---

## 🗄 Database Layer

Database support powered by **MariaDB**.

Features:

* Typed queries
* Repository pattern
* Centralized database access
* Clean abstraction layer

# 🎯 Why I built this

Most FiveM projects become difficult to maintain as they grow.

This project was built to explore how professional software architecture principles can be applied to game server development.

Throughout this project I learned:

* Software architecture
* Dependency Injection
* Design Patterns
* Modular programming
* TypeScript at scale
* Backend organization
* Large project structure
